1. What is Git, what is Github, and what is the difference between the two?
Git: Is a version control system, where you can track changes in your source code, Github: A website where you can track changes in your code Difference: A website that is buid around Git 
2. What is the difference between a local repository and a remote repository?
Local is the physical copy that is on your computer, Remote: The copy that is on the internet.
3. What does the push command do in Git?
Take the Local changes, into the remote Repo
4. What does the commit command do in Git?
Saves the changes in the Local Repo
5. What is Github Desktop, & why are we using it?
A app that lets you use Git and Github without having to type Git commands, we use it for the simplicity.
